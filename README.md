# SAPAMERCAT 🛒

## Descripció
Aplicació en Java per gestionar un carret de la compra amb diferents tipus de productes:
- Alimentació
- Tèxtil
- Electrònica

## Funcionament
L'aplicació permet:
- Introduir productes
- Mostrar el carret de compra
- Passar per caixa i generar un tiquet

## Decisions preses
- S'ha utilitzat herència per diferenciar tipus de productes
- S'ha aplicat polimorfisme per calcular els preus
- S'ha utilitzat la col·lecció Map per agrupar productes
- S'han implementat streams i lambda expressions

## Tecnologies
- Java
- Collections (List, Map)
- Streams
